# Заняття 0. Стартовий застосунок «Облік особового складу»

Навчальний вебзастосунок для курсу «Технології розгортання кросплатформених серверних застосунків».
Це **вихідна точка**: спочатку ви запускаєте його просто на своєму комп'ютері, а потім на заняттях
упаковуєте в Docker, розгортаєте на віртуальній машині, налаштовуєте nginx, HTTPS, мережевий
захист і автоматичне розгортання з GitLab.

Цей документ пояснює, що це за застосунок і як запустити його в себе **без Docker**.

---

## 1. Що це за застосунок

Невеликий облік особового складу підрозділу. Він вміє:

- показувати **головну сторінку** зі зведенням: скільки людей усього, скільки на місці, скільки відсутніх,
  і таблицю «підрозділ × статус»;
- вести **список особового складу**: пошук за ПІБ, фільтри за підрозділом і статусом, додавання,
  зміна й видалення записів;
- пускати **одного користувача** за логіном і паролем (вхід видає токен JWT);
- відповідати на **`/health`**: вона показує, що сервер живий, його версію та стан бази даних.

Статуси особового складу: `present` (на місці), `leave` (у відпустці), `sick` (хворіє),
`mission` (у відрядженні), `duty` (у наряді).

**Застосунок стартує порожнім.** Записів немає, поки ви їх не додасте. На головній сторінці є кнопка
«Додати 12 демонстраційних записів», якщо потрібні дані для спроб.

### З чого він складається

| Частина | Технології | Де лежить |
|---|---|---|
| Сервер (API) | Java 21, Spring Boot, Spring Data JPA | `server/src/main/java` |
| База даних | локально H2 (в пам'яті); у Docker і на сервері MySQL 8 | `server/src/main/resources` |
| Веб-сторінка | чистий HTML, CSS і JavaScript, без збирання | `client/` |
| Тести | JUnit 5 | `server/src/test/java` |
| Збирання | Maven (вже вбудований у проєкт: `mvnw`) | `server/pom.xml` |

### Структура папок


## 2. Що потрібно встановити

Потрібні **JDK 21** (Java Development Kit) і **git** (щоб забрати проєкт з GitLab). Maven, база даних і Docker
**не потрібні**. Редактор бажаний, найзручніше IntelliJ IDEA (Community-версії достатньо).

Спочатку перевірте git:

```powershell
# Показує версію git. Якщо команда не знайдена, встановіть git за наступним блоком
git --version
```

```powershell
# Windows: встановлення git через winget. Після нього закрийте термінал і відкрийте новий
winget install Git.Git
```

```bash
# Ubuntu / Debian
sudo apt install git

# macOS
brew install git
```

Тепер Java.

Перевірте, чи Java вже є. Відкрийте термінал (Windows: PowerShell) і виконайте:

```powershell
# Показує версію Java. Потрібна версія 21, рядок виду: openjdk version "21.0.x"
java -version

# Компілятор Java. Якщо цієї команди немає, а java є, встановлено лише JRE, а не JDK
javac -version
```

Якщо команди не знайдені або версія нижча за 21, встановіть JDK 21 одним із способів.

**Windows (рекомендовано):**

```powershell
# winget — менеджер пакетів Windows 10/11. Temurin — безкоштовна збірка OpenJDK від Eclipse
winget install EclipseAdoptium.Temurin.21.JDK
```

Після встановлення **закрийте термінал і відкрийте новий**, щоб оновився шлях до Java, і ще раз
виконайте `java -version`.

**Ubuntu / Debian:**

```bash
sudo apt update
sudo apt install openjdk-21-jdk
```

**macOS:**

```bash
brew install --cask temurin@21
```

**Через IntelliJ IDEA:** якщо JDK не знайдено, IDE запропонує завантажити його сама:
File → Project Structure → SDKs → «+» → Download JDK → Vendor: Eclipse Temurin, Version: 21.

## 4. Запуск

### Варіант А: IntelliJ IDEA (найпростіший)

1. File → Open → оберіть папку **`server`** (ту, де лежить `pom.xml`), а не окремий файл і не батьківську папку.
2. Дочекайтеся, поки внизу зникне індикатор завантаження залежностей (перший раз це
   2–5 хвилин, потрібен інтернет).
3. Якщо угорі червоне «Project JDK is not defined», натисніть «Setup SDK» і оберіть JDK 21
   (або File → Project Structure → Project → SDK).
4. У дереві відкрийте `src/main/java/edu/trk/start_project/StartProjectApplication.java`
   і натисніть **зелену стрілку** поруч із методом `main`.
5. У консолі внизу має з'явитись рядок `Started StartProjectApplication in ... seconds`.
6. Зупинка: червоний квадрат на панелі Run.

### Варіант Б: термінал

У терміналі перейдіть у папку `server`:

```powershell
# Windows (PowerShell). Заходимо в папку server (там лежить pom.xml)
cd server
# mvnw.cmd — Maven, вбудований у проєкт; перший запуск сам завантажить усе потрібне
.\mvnw.cmd spring-boot:run
```

```bash
# Linux / macOS. Заходимо в папку server; chmod потрібен один раз, щоб файл можна було виконувати
cd server
chmod +x mvnw
./mvnw spring-boot:run
```

Зупинка: `Ctrl+C` у тому ж вікні.

> Якщо `mvnw` пише «JAVA_HOME not found», а `java -version` працює, закрийте й знову відкрийте
> термінал. Якщо не допомогло, запускайте через IntelliJ (варіант А): він використовує власний JDK.

## 5. Перевірка, що все працює

1. Відкрийте в браузері **http://localhost:8000**
2. Увійдіть: логін `admin`, пароль `admin` (це значення для локальної роботи, див. розділ 7).
3. На головній сторінці натисніть «Додати 12 демонстраційних записів», щоб побачити зведення.
4. Перейдіть у «Особовий склад»: спробуйте пошук, фільтри, додавання, зміну й видалення.
5. Сторінка «Про систему» показує версію, середовище та стан бази даних.

Перевірка з терміналу:

```powershell
# Windows: пишіть саме curl.exe. Без «.exe» PowerShell запустить інший інструмент
# -s прибирає індикатор завантаження
curl.exe -s http://localhost:8000/health
```

Очікувана відповідь:

```json
{"status":"ok","version":"dev","env":"development","database":"up","database_mode":"H2"}
```

Без токена доступу немає, це правильно:

```powershell
# Очікуємо 401: без входу список закритий
curl.exe -s -w "`nHTTP %{http_code}`n" http://localhost:8000/personnel

# Вхід: у відповіді буде access_token
curl.exe -s -X POST http://localhost:8000/auth/login -H "Content-Type: application/json" -d '{\"username\":\"admin\",\"password\":\"admin\"}'
```

(У Linux і macOS лапки в `-d` пишуться без зворотних скісних рисок: `-d '{"username":"admin","password":"admin"}'`.)

## 6. Адреси API

Усі адреси працюють і з префіксом `/api` (наприклад `/api/personnel`). Саме так до них звертається
веб-сторінка: пізніше, у Docker, цей префікс буде відкидати nginx.

| Метод і адреса | Потрібен токен | Що робить |
|---|---|---|
| `GET /health` | ні | стан сервера: версія, середовище, база даних. `200` або `503`, якщо база недоступна |
| `POST /auth/login` | ні | логін і пароль → токен `access_token` |
| `GET /auth/me` | так | хто увійшов |
| `GET /personnel` | так | список; параметри `search`, `unit`, `status`, `page`, `size` |
| `GET /personnel/summary` | так | підсумки: `total`, `by_status`, `by_unit` |
| `GET /personnel/{id}` | так | один запис |
| `POST /personnel` | так | створити (`201`) |
| `PUT /personnel/{id}` | так | змінити |
| `DELETE /personnel/{id}` | так | видалити (`204`) |

Токен передається заголовком `Authorization: Bearer <токен>`.
Помилки: `401` (немає або недійсний токен), `400` (неправильні дані), `404` (запису немає).

## 7. Налаштування через змінні середовища

Застосунок читає налаштування зі змінних середовища, значення за замовчуванням підходять для
локальної роботи. Саме так його налаштовуватимуть у Docker і на сервері (файл `.env`).

| Змінна | За замовчуванням | Призначення |
|---|---|---|
| `APP_PORT` | `8000` | порт, на якому слухає застосунок |
| `APP_ENV` | `development` | назва середовища (`production` вмикає суворі перевірки) |
| `APP_VERSION` | `dev` | версія, її видно в `/health` і на сторінці «Про систему» |
| `ADMIN_USERNAME` | `admin` | логін єдиного користувача |
| `ADMIN_PASSWORD` | `admin` | його пароль |
| `JWT_SECRET` | `dev-only-...` | секрет для підпису токенів, не менше 32 символів |
| `JWT_EXPIRE_MINUTES` | `480` | скільки хвилин діє токен (480 = 8 годин) |
| `CLIENT_DIR` | `../client` | де лежить веб-сторінка |
| `SPRING_PROFILES_ACTIVE` | порожньо | `mysql` вмикає підключення до MySQL (розділ 8) |

**Як задати змінну лише на один запуск:**

```powershell
# Windows PowerShell: змінна діє тільки в цьому вікні, поки його не закрили
$env:APP_PORT = "9000"
$env:APP_VERSION = "1.0.0"
.\mvnw.cmd spring-boot:run
```

```bash
# Linux / macOS: змінна діє лише для цієї команди
APP_PORT=9000 APP_VERSION=1.0.0 ./mvnw spring-boot:run
```

В IntelliJ: Run → Edit Configurations → поле «Environment variables» (`APP_PORT=9000;APP_VERSION=1.0.0`).

**Правило безпеки.** Коли `APP_ENV=production`, застосунок **відмовиться стартувати**, якщо пароль
лишився `admin` або коротший за 8 символів, чи секрет JWT лишився типовим. Це навмисно: небезпечні
значення за замовчуванням не мають потрапити на сервер. Реальні паролі й секрети зберігають у файлі
`.env`, який **ніколи не додається в git** (він є в `.gitignore`).

## 8. База даних

**За замовчуванням** застосунок використовує **H2 в пам'яті**: нічого встановлювати не треба, але
**дані зникають при кожній зупинці** застосунку. Для локального знайомства з проєктом цього досить.

**Режим MySQL** потрібен у Docker і на сервері (а ще, якщо у вас вже встановлено MySQL). Він
вмикається змінною `SPRING_PROFILES_ACTIVE=mysql` і читає з'єднання зі змінних:

| Змінна | Приклад | Призначення |
|---|---|---|
| `DB_HOST` | `localhost` | адреса сервера бази (в Docker це ім'я контейнера, наприклад `db`) |
| `DB_PORT` | `3306` | порт MySQL |
| `DB_NAME` | `personnel` | назва бази (її потрібно створити заздалегідь) |
| `DB_USERNAME` | `app` | користувач бази |
| `DB_PASSWORD` | `...` | пароль користувача |

Таблиця створюється автоматично під час першого запуску. Якщо база ще не готова, застосунок
чекає на неї до 60 секунд, а потім зупиняється з помилкою. Саме це ви побачите на заняттях, коли
контейнер із застосунком стартує раніше за контейнер із базою.

## 11. Типові проблеми

| Симптом | Причина і що робити |
|---|---|
| `java` / `javac` «не розпізнано» | JDK не встановлено або термінал відкрито до встановлення. Розділ 2, потім новий термінал |
| `Port 8000 was already in use` | порт зайнятий (можливо, попередній запуск не зупинено). Зупиніть його або запустіть з іншим портом: `$env:APP_PORT="8001"` |
| Maven нічого не завантажує | немає інтернету або його блокує проксі. Перевірте з'єднання й повторіть |
| У браузері стара сторінка | `Ctrl+F5` (оновлення без кешу) |
| «Невірний логін або пароль» | за замовчуванням `admin` / `admin`; якщо задано `ADMIN_PASSWORD`, вводьте його |
| Раптово повернувся екран входу | токен дійсний 8 годин або застосунок перезапустили зі зміненим `JWT_SECRET`. Увійдіть знову |
| Зникли всі записи | це H2 в пам'яті: після зупинки застосунку дані очищаються (розділ 8) |
| `JWT_SECRET must be at least 32 characters` | секрет коротший за 32 символи; задайте довший |
| IntelliJ підкреслює все червоним | зачекайте на завершення імпорту; потім Maven-панель → кнопка «Reload All Maven Projects» |

## 12. Що далі в курсі

Цей застосунок ви будете розгортати на кожному занятті: збирати в Docker-образ, запускати разом із
MySQL через Docker Compose, публікувати образи в реєстрі GitLab, розгортати на віртуальній машині,
ставити перед ним nginx із HTTPS, закривати зайві порти файрволом, налаштовувати автоматичне
розгортання (CI/CD), знімати резервні копії бази й дивитись на метрики. Код застосунку для цього
змінювати майже не доведеться: ви будете працювати з тим, що довкола нього.
